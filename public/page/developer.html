开发接入

应用分发中心向 APP 提供标准 HTTP 接口，覆盖「更新检测、安装包下载、用户反馈、崩溃上报」四大场景。APP 只需按 app_code 接入即可与平台互通，无需额外 SDK 依赖。

快速开始

  1. 在管理后台 → 应用管理中创建应用，获取 app_code（如 kuaidi）。
  2. 上传安装包并发布版本，配置是否强制升级、灰度规则、最低版本号等。
  3. 在 APP 启动时调用更新检测接口，命中新版本后按 download_url 下载并校验 md5/sha256。
  4. 需要时调用反馈/崩溃接口，自动汇总至后台工单与崩溃日志。

更新检测

APP 启动时调用，携带当前版本号、平台、渠道与设备信息，返回是否需更新及新版本详情。

GET /api/v1/app/update/check

按 应用 → 版本号 → 平台/架构 → 渠道 → 最低版本 → 灰度规则 → 设备 的决策链判断是否需要升级。

请求参数

参数类型必填说明
app_codestring必填应用唯一编码，管理后台创建应用时分配
version_codeint必填当前版本号（数字，如 100）
version_namestring必填当前版本名（如 1.0.0）
platformstring必填平台：android、ios、windows、macos、linux
architecturestring可选CPU 架构：arm64-v8a、armeabi-v7a、x86_64、universal 等
channelstring可选渠道编码，默认 official
device_idstring可选设备唯一标识，用于灰度与崩溃追踪
os_versionstring可选操作系统版本号

示例代码

cURL Java (OkHttp) iOS (URLSession) JavaScript 
# 更新检测（GET 请求，参数放在 URL 中）
curl "https://your-domain/api/v1/app/update/check?app_code=your_app&version_code=100&version_name=1.0.0&platform=android&os_version=13&architecture=arm64-v8a&channel=official&device_id=dev_001"

# 有更新时下载安装包（302 跳转至存储地址）
curl -L "https://your-domain/download/12" -o your_app_1.1.0.apk

# 校验文件完整性
md5sum your_app_1.1.0.apk
// Android - OkHttp 示例
OkHttpClient client = new OkHttpClient();
HttpUrl url = HttpUrl.parse("https://your-domain/api/v1/app/update/check").newBuilder()
    .addQueryParameter("app_code", "your_app")
    .addQueryParameter("version_code", "100")
    .addQueryParameter("version_name", "1.0.0")
    .addQueryParameter("platform", "android")
    .addQueryParameter("device_id", Build.SERIAL)
    .build();
Request request = new Request.Builder().url(url).build();
client.newCall(request).enqueue(new Callback() {
    @Override public void onFailure(Call call, IOException e) { /* 重试/忽略 */ }
    @Override public void onResponse(Call call, Response response) throws IOException {
        JSONObject json = new JSONObject(response.body().string());
        if (json.getInt("code") == 0) {
            JSONObject data = json.getJSONObject("data");
            boolean has = data.getBoolean("has_update");
            // 有新版本时提示用户下载
        }
    }
});
// iOS - URLSession 示例
let url = URL(string: "https://your-domain/api/v1/app/update/check?app_code=your_app&version_code=100&version_name=1.0.0&platform=ios&device_id=\(UIDevice.current.identifierForVendor?.uuidString ?? "")")!
let task = URLSession.shared.dataTask(with: url) { data, response, error in
    guard let data = data else { return }
    do {
        let json = try JSONSerialization.jsonObject(with: data) as? [String: Any]
        if let code = json?["code"] as? Int, code == 0,
           let dataObj = json?["data"] as? [String: Any],
           let hasUpdate = dataObj["has_update"] as? Bool, hasUpdate {
            // 弹出更新提示
        }
    } catch { }
}
task.resume()
// JavaScript / Web 示例
async function checkUpdate() {
  const params = new URLSearchParams({
    app_code: 'your_app',
    version_code: '100',
    version_name: '1.0.0',
    platform: 'web',
    device_id: 'web_001'
  });
  const res = await fetch('/api/v1/app/update/check?' + params.toString());
  const json = await res.json();
  if (json.code === 0 && json.data?.has_update) {
    console.log('有新版本', json.data.version_name, json.data.download_url);
  }
}

安装包下载

通过版本 ID 或应用编码获取最新安装包，支持渠道分流与二维码下载。

GET /download/{version_id}

返回 302 重定向至安全存储地址，同时记录下载日志与渠道统计。

GET /download/{app_code}?channel={channel_code}

按应用编码 + 渠道编码获取最新版本，常用于渠道二维码下载。

参数类型必填说明
version_idint必填版本 ID（更新检测接口返回的 version_id）
app_codestring必填应用唯一编码
channelstring可选渠道编码，默认 official

用户反馈

提交问题、建议或截图附件，平台自动生成工单流转处理。

POST /api/v1/feedback/create

创建反馈并自动生成工单号，限流 20 次/60 秒。

参数类型必填说明
app_codestring必填应用编码
typestring必填类型：bug / suggestion / complaint / other
titlestring必填标题
contentstring可选详细描述
contactstring可选联系方式（邮箱/手机）
device_idstring可选设备 ID
app_versionstring可选应用版本名
os_versionstring可选操作系统版本
device_modelstring可选设备型号
channelstring可选渠道编码
cURL 
# 提交用户反馈
curl -X POST "https://your-domain/api/v1/feedback/create" \
  -d "app_code=your_app&type=bug&title=登录偶发失败&content=在弱网环境下点击登录按钮无响应&contact=user@mail.com&device_id=dev_001&app_version=1.0.0&os_version=13&device_model=Pixel+8&channel=official"

# 返回
{"code":0,"message":"success","data":{"feedback_id":88,"ticket_no":"BUG-20260923-088"}}

崩溃上报

APP 捕获未处理异常后上报堆栈与设备环境，帮助研发快速定位线上问题。限流 30 次/60 秒。

POST /api/v1/crash/report
参数类型必填说明
app_codestring必填应用编码
version_namestring必填版本名
version_codeint必填版本号
device_idstring必填设备 ID
device_modelstring可选设备型号
os_versionstring可选系统版本
error_messagestring可选错误摘要
stack_tracestring可选完整堆栈
occurred_atstring可选发生时间（格式：2026-09-23 10:00:00）
cURL 
# 上报崩溃
curl -X POST "https://your-domain/api/v1/crash/report" \
  -d "app_code=your_app&version_name=1.0.0&version_code=100&device_id=dev_001&device_model=Pixel+8&os_version=13&error_message=NullPointerException&stack_trace=at+com.app.Main.onCreate&occurred_at=2026-09-23+10:00:00"

# 返回
{"code":0,"message":"success"}

错误码表

code含义常见场景
0成功正常返回
10001参数缺失必填参数未传
10002参数格式错误数值字段传了非数字
10003参数校验失败格式正则校验不通过（如 App Code、渠道编码）
10004资源已存在重复创建（同名应用、重复渠道编码）
10005资源不存在或已停用查询不到对应记录
10006操作失败业务逻辑不允许（如删除已发布版本）
10007权限不足当前角色无对应权限点
10008禁止操作如禁用自己账号、移除自己超级管理员角色
401未登录或登录已失效Token 过期或无效
403无权限RbacCheck 拦截（缺少对应 permission）
404接口或资源不存在URL 错误或版本/应用不存在
429请求过于频繁接口限流触发（登录/反馈/上传等）
500服务器内部错误异常情况，需联系管理员排查

接入流程

Step 1 后台创建应用 → 获取 app_code
Step 2 上传安装包并发布 → 配置灰度/强制更新规则
Step 3 APP 启动调用 /api/v1/app/update/check → 判断是否升级
Step 4 命中升级 → 按 download_url 下载 → 校验 md5/sha256 → 安装
Step 5 异常时调用 /api/v1/crash/report，用户反馈调用 /api/v1/feedback/create
