⭐核心特性

🛡
下载安全校验
所有安装包经 MD5 / SHA1 / SHA256 多重哈希校验，APK/IPA 签名指纹提取与验证，确保分发包的完整性与来源可信。
🌐
稳定分发
支持全量 / 灰度 / 定向 / A/B 实验分组发布，按设备/用户/渠道/百分比精准投放，一键回滚与暂停，保障升级稳定性。
🔄
版本发布与升级机制
智能更新检测引擎：按应用→版本号→平台/架构→渠道→最低版本→灰度规则→设备→实验组 决策链，精准推送可用版本。
📊
全链路监控
下载统计、留存分析、漏斗分析、实时数据看板、性能监控与崩溃上报符号化，数据驱动版本迭代。
🔐
访问控制
下载密码保护、访问类型控制（公开/密码/白名单）、邀请链接管理、测试人员群组，多维度管控分发权限。
🚀
增量更新
服务端 bsdiff 差分包自动生成，客户端合并还原，显著降低升级流量消耗，提升大版本迭代效率。

📱全平台支持

平台支持主流操作系统与架构，覆盖移动端、桌面端及国产操作系统：

🌐 HarmonyOS 🤖 Android 🍎 iOS 🪟 Windows 🖥️ macOS 🐧 Linux
  • 移动端：Android（APK）、iOS（IPA / itms-services 企业分发）、HarmonyOS（HAP / APP）
  • 桌面端：Windows（EXE / ZIP）、macOS（DMG / ZIP）、Linux（AppImage / BIN / TAR）
  • 架构适配：支持按设备架构（arm64 / x86 / x86_64 等）精准匹配安装包
  • SDK 接入：提供 Android（Java）与 iOS（Swift）应用内更新 SDK，封装更新检测、下载、安装全流程

📖下载与使用指引

  • 前台下载：访问首页或应用专属下载页，选择对应平台后获取安装包或扫码下载。
  • 版本历史：在应用下载页点击「历史版本」，查看并下载过往已发布的正式版本。
  • API 接入：开发者可阅读「开发接入」文档，按 app_code 接入更新检测、反馈上报、崩溃上报等标准接口。
  • 后台管理：管理员通过「管理后台」进行应用创建、安装包上传、版本发布、渠道配置、统计查看与权限管控。
  • 安全提醒：下载后请核对版本号、平台与文件哈希是否与页面展示一致；发现异常请通过 App 内反馈通道联系我们。
